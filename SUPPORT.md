# Support

Open an issue on this repository using the bug report or feature request form. There is no
guaranteed response time.

Include the following.

- App version and build (Tweaks > About), iOS version and device model.
- How you installed it (AltStore, SideStore, Feather, RyukSign, FlareStore, Sideloadly, other).
- Steps to reproduce, what you expected and what happened.
- The channel name, if the problem is with a public stream.

Never post passwords, tokens, cookies, client secrets, signed stream URLs, certificates or
provisioning profiles. Check screenshots and diagnostic exports before sharing them. Local
playback diagnostics are off by default and only leave your device when you share them.

For privacy questions see [PRIVACY.md](PRIVACY.md). For security problems, do not open a
public issue. Follow [SECURITY.md](SECURITY.md).
